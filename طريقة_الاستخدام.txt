========================================================================
     📱 دليل تشغيل الموبايل وايرلس لمطوري التطبيقات (Wireless ADB)
========================================================================

🎯 الهدف الأساسي للأداة:
- تشغيل الموبايل وايرلس تماماً بدون أي وصلة USB.
- تمكين مطوري (Flutter / Android Studio / VS Code / React Native)
  من عمل Run و Debug و Hot Reload على الهاتف الحقيقي لاسلكياً بسرعة فائقة.

------------------------------------------------------------------------
🚀 خطوات التشغيل البسيطة:
------------------------------------------------------------------------

الخطوة 1: (تفعيل الاتصال - لمرة واحدة فقط بالكابل):
1. وصل الموبايل بالكمبيوتر عبر كابل USB.
2. اضغط دبل كليك على:
   [1_تفعيل_الوايرلس_لأول_مرة_بالوصلة.bat]
3. الأداة ستقوم تلقائياً بالتعرف على الموبايل واستخراج الـ IP وفتح بورت 5555.
4. بمجرد ظهور رسالة النجاح، **افصل كابل الـ USB تماماً!**

الخطوة 2: (التطوير اللاسلكي من المحرر):
- افتح Android Studio أو VS Code أو Antigravity IDE.
- ستجد هاتفك الحقيقي ظاهراً في قائمة الأجهزة (Devices) كجهاز وايرلس.
- يمكنك الآن عمل Run و Hot Reload في ثوانٍ بدون أسلاك!

الخطوة 3: (إعادة الاتصال لاحقاً بدون وصلة نهائياً):
- في أي يوم قادم، تأكد فقط أن اللابتوب والموبايل على نفس شبكة الواي فاي.
- اضغط دبل كليك على:
   [2_إعادة_الاتصال_الوايرلس_بدون_وصلة.bat]
- سيتصل بالموبايل تلقائياً في ثانية واحدة بدون الحاجة لكابل نهائياً!
